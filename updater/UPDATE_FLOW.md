# OpenClaw 更新流程文档

## 概述

本文档详细描述 OpenClaw 更新程序的完整工作流程，包括版本检查、下载、备份、安装和回滚等环节。

## 详细流程说明

### 1. 初始化阶段

**输入**: 命令行参数、环境变量、配置文件

**处理**:
1. 解析命令行参数（-check, -yes, -adapter 等）
2. 检测操作系统类型和架构
3. 确定默认路径（安装目录、配置目录、备份目录）
4. 加载配置文件（如果存在）
5. 初始化日志系统

**输出**: 配置好的 Updater 实例

**错误处理**:
- 配置文件解析失败：使用默认配置继续
- 路径检测失败：报告错误并退出

### 2. 版本检查阶段

**输入**: 版本检查 URL 或本地路径

**处理**:
1. 发送 HTTP GET 请求获取远程版本清单
2. 或从本地目录读取 manifest.json
3. 读取本地已安装版本（从 .version 文件或执行二进制）
4. 语义化版本比较（遵循 SemVer 规范）
5. 检查适配器与核心版本兼容性

**输出**: UpdateInfo 结构体，包含可更新组件列表

**错误处理**:
- 网络请求失败：重试 3 次后报告错误
- 清单解析失败：报告错误并退出
- 无可用更新：正常退出，返回码 1

### 3. 用户确认阶段

**输入**: UpdateInfo

**处理**:
1. 格式化显示更新信息
2. 列出所有可更新组件
3. 显示版本变更（当前版本 -> 新版本）
4. 等待用户输入（y/N）

**输出**: 用户确认结果

**特殊情况**:
- 使用 -yes 参数：自动确认
- 使用 -dry-run 参数：跳过确认，仅显示

### 4. 下载阶段

**输入**: 更新包下载 URL 列表

**处理**:
1. 创建临时目录（/tmp/openclaw-update-xxx）
2. 并发下载多个组件包
3. 显示下载进度
4. 计算 SHA256 校验和
5. 与清单中的校验和比对

**输出**: 下载好的包文件路径映射

**错误处理**:
- 下载失败：重试 3 次
- 校验和失败：删除文件，报告错误
- 磁盘空间不足：清理临时文件，报告错误

### 5. 备份阶段

**输入**: 当前安装路径、备份目录

**处理**:
1. 停止运行中的 OpenClaw 服务
2. 创建备份目录（backup-YYYYMMDD-HHMMSS）
3. 复制二进制文件到备份目录
4. 复制配置文件到备份目录
5. 生成备份清单（manifest.json）
6. 记录备份元数据（时间、版本、组件列表）

**输出**: BackupInfo

**错误处理**:
- 服务停止失败：强制终止或报告错误
- 备份失败：清理部分备份，报告错误
- 磁盘空间不足：报告错误，询问是否继续

### 6. 安装阶段

**输入**: 下载的包文件、安装路径

**处理**:
1. 解压更新包到临时位置
2. 替换二进制文件（原子性操作）
   - 写入新文件到临时位置
   - 重命名旧文件（备份）
   - 重命名新文件到目标位置
3. 合并配置文件（保留用户设置）
4. 设置文件权限（二进制 0755，配置 0640）

**输出**: 安装完成的组件列表

**错误处理**:
- 解压失败：清理，触发回滚
- 权限不足：报告错误，触发回滚
- 文件被占用：等待或强制替换

### 7. 验证阶段

**输入**: 安装路径

**处理**:
1. 检查文件完整性（存在性、权限）
2. 执行二进制文件测试（--version）
3. 验证配置文件可加载
4. 测试配置文件语法

**输出**: 验证结果

**错误处理**:
- 验证失败：触发自动回滚

### 8. 完成阶段

**输入**: 更新结果

**处理**:
1. 清理临时下载文件
2. 清理超出保留数量的旧备份
3. 写入新版本记录
4. 启动 OpenClaw 服务
5. 显示更新完成信息

**输出**: 更新完成状态

## 配置保留策略

更新过程中，用户配置按以下策略处理：

1. **核心配置** (openclaw.yaml)
   - 保留用户自定义的设置
   - 合并新的默认配置项
   - 保留敏感信息（密码、密钥等）

2. **适配器配置** (*-adapter.yaml)
   - 保留 webhook URL、 corp_id 等连接信息
   - 保留自定义规则和调整参数
   - 合并新的配置选项

3. **配置合并算法**
   ```
   新配置 = 默认配置
   对于每个用户配置项:
       如果键存在于新配置:
           如果是对象: 递归合并
           否则: 使用用户值
       否则:
           保留用户值（向后兼容）
   ```

## 错误码定义

| 错误码 | 含义 | 说明 |
|--------|------|------|
| 0 | 成功 | 更新/检查成功完成 |
| 1 | 无更新 | 检查模式：没有可用更新 |
| 2 | 用户取消 | 用户取消了更新 |
| 3 | 网络错误 | 无法连接到更新服务器 |
| 4 | 验证失败 | 校验和或签名验证失败 |
| 5 | 安装失败 | 安装过程中出错 |
| 6 | 回滚失败 | 回滚过程中出错 |
| 7 | 权限错误 | 权限不足 |
| 8 | 磁盘空间不足 | 磁盘空间不足 |
| 9 | 配置错误 | 配置文件错误 |
| 10 | 未知错误 | 其他未分类错误 |

## 安全注意事项

1. **下载安全**
   - 强制使用 HTTPS
   - 验证 TLS 证书
   - 验证文件校验和

2. **安装安全**
   - 原子性文件替换
   - 保留文件权限
   - 防止路径遍历攻击

3. **备份安全**
   - 备份目录设置 0750 权限
   - 敏感配置文件加密存储（可选）
   - 定期清理旧备份

## 性能考虑

1. **并发下载**: 多个组件同时下载
2. **增量更新**: 未来支持二进制差分更新
3. **压缩传输**: 使用 gzip 压缩
4. **缓存机制**: 缓存版本清单

## 扩展接口

更新程序预留以下扩展接口：

1. **自定义更新源**: 支持私有部署的更新服务器
2. **钩子脚本**: 更新前后执行自定义脚本
3. **插件机制**: 支持自定义验证逻辑
