============================================
   OpenClaw 跨平台 AI 助手安装器
============================================

欢迎使用 OpenClaw！这是一个可以在 macOS、Windows、Linux 上运行的
AI 助手，支持企业微信、钉钉、飞书等 IM 平台。

============================================
   安装步骤 (非常简单！)
============================================

【Windows 用户】
双击运行：install.bat

【macOS 用户】
双击运行：install-mac.command

【Linux 用户】
在终端中运行：
    bash install-linux.sh

============================================
   安装器会做什么？
============================================

1. 自动检测你的系统类型 (Windows/Mac/Linux, x64/ARM64)
2. 让你选择安装方式：
   - 安装到系统目录 (推荐，所有用户可用)
   - 安装到用户目录 (无需管理员权限)
   - 便携模式 (直接从U盘运行)
3. 自动复制文件到合适的位置
4. 启动配置界面，自动打开浏览器
5. 在浏览器中完成 IM 配置

============================================
   配置界面
============================================

安装器会启动一个 Web 界面，地址是：
    http://localhost:18080

如果浏览器没有自动打开，请手动访问上面的地址。

配置内容包括：
- AI 模型选择 (OpenAI/Anthropic等)
- 企业微信机器人配置
- 钉钉机器人配置
- 飞书机器人配置

============================================
   安装完成后
============================================

Windows: 可以在开始菜单找到 OpenClaw
macOS/Linux: 在终端输入 openclaw 即可使用

常用命令：
    openclaw gateway          # 启动服务
    openclaw agent -m "你好"   # 发送消息
    openclaw doctor           # 检查状态

============================================
   离线说明
============================================

本安装包已包含所有需要的文件，无需联网即可安装。
安装后如需更新，可使用 openclaw-update 命令。
