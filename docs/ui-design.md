# OpenClaw Web 配置界面 UI 设计文档

## 概述
Web 配置界面用于配置 OpenClaw AI 助手，支持企业微信、钉钉、飞书三个 IM 渠道的接入配置。

## 设计原则
- 简洁现代的视觉风格
- 清晰的步骤引导
- 表单验证即时反馈
- 响应式布局（桌面优先）

## 页面结构

### 1. 欢迎页

**页面目的**：介绍 OpenClaw 并引导用户开始配置

**布局**：
```
+------------------------------------------+
|              [OpenClaw Logo]             |
|                                          |
|           欢迎使用 OpenClaw              |
|     智能 AI 助手，一键连接企业 IM        |
|                                          |
|    [企业微信图标] [钉钉图标] [飞书图标]   |
|                                          |
|         [      开始配置      ]           |
+------------------------------------------+
```

**元素清单**：
| 元素 | 类型 | 说明 |
|------|------|------|
| Logo | 图片 | OpenClaw 品牌标识 |
| 主标题 | 文字 | "欢迎使用 OpenClaw" |
| 副标题 | 文字 | "智能 AI 助手，一键连接企业 IM" |
| IM 图标组 | 图标 | 展示支持的三个平台 |
| 开始按钮 | 按钮 | 进入基础配置页 |

---

### 2. 基础配置页

**页面目的**：配置 AI 模型和 Gateway 服务端口

**布局**：
```
+------------------------------------------+
|  [Logo]              步骤 1 / 5          |
+------------------------------------------+
|                                          |
|           基础配置                       |
|     配置 AI 模型和服务端口              |
|                                          |
|  AI 模型提供商                           |
|  [请选择模型提供商    ▼]                 |
|                                          |
|  AI API Key                              |
|  [****************************]          |
|  [?] 如何获取 API Key                    |
|                                          |
|  Gateway 端口                            |
|  [8080                        ]          |
|  [?] 服务监听端口，默认 8080             |
|                                          |
|         [  上一步  ]  [  下一步  ]       |
+------------------------------------------+
```

**字段清单**：
| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| AI 模型提供商 | 下拉选择 | 是 | - | 选项：OpenAI、Anthropic、Azure OpenAI、本地模型 |
| AI API Key | 密码输入 | 是 | - | API 密钥，显示为掩码 |
| Gateway 端口 | 数字输入 | 是 | 8080 | 1-65535 |

### 3. 企业微信配置页

**页面目的**：配置企业微信接入参数

```
+------------------------------------------+
|  [Logo]              步骤 2 / 5          |
+------------------------------------------+
|                                          |
|        [企业微信图标]                    |
|           企业微信配置                   |
|     配置企业微信应用参数                |
|                                          |
|  CorpID (企业 ID)                        |
|  [wwxxxxxxxxxxxxxxxx                     ] |
|                                          |
|  AgentID (应用 ID)                       |
|  [1000002                                 ] |
|                                          |
|  Secret (应用密钥)                       |
|  [****************************]          |
|                                          |
|  Token (消息加密令牌)                    |
|  [xxxxxxxxxxxxxxxxxxxxxxxxxxxx]          |
|                                          |
|  EncodingAESKey (消息加密密钥)           |

|                                          |
```

**字段清单**：

| Secret | 密码输入 | 是 | - | 应用密钥 |
| Token | 文本输入 | 否 | - | 消息加密令牌，用于回调验证 |
| EncodingAESKey | 文本输入 | 否 | - | 43位消息加密密钥 |
| 启用接收消息 | 开关 | 否 | 关闭 | 是否启用消息接收功能 |

## 页面跳转逻辑

```
欢迎页 → 基础配置 → 企业微信 → 钉钉 → 飞书 → 完成页
            ↑         ↑         ↑       ↑
            └─────────┴─────────┴───────┘ (上一步)
```

## 视觉风格规范

### 色彩
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色调 | #1890ff | OpenClaw 品牌蓝 |
| 成功色 | #52c41a | 成功状态 |
| 警告色 | #faad14 | 警告提示 |
| 错误色 | #f5222d | 错误提示 |
| 文字主色 | #262626 | 主要文字 |
| 文字次色 | #595959 | 次要文字 |
| 边框色 | #d9d9d9 | 输入框边框 |
| 背景色 | #f5f5f5 | 页面背景 |

### 字体
- 主字体：-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial
- 标题字号：24px
- 正文字号：14px
- 辅助文字：12px

### 间距
- 页面内边距：24px
- 卡片内边距：24px
- 表单字段间距：20px
- 按钮间距：12px

## 响应式断点
| 断点 | 宽度 | 布局调整 |
|------|------|----------|
| 桌面 | >= 1024px | 标准布局 |
| 平板 | 768px - 1023px | 保持布局，缩小间距 |
| 手机 | < 768px | 单列布局，堆叠显示 |

## 表单验证规则

| 字段 | 验证规则 | 错误提示 |
|------|----------|----------|
| AI 模型提供商 | 必选 | 请选择 AI 模型提供商 |
| API Key | 非空，长度 >= 10 | 请输入有效的 API Key |
| Gateway 端口 | 1-65535 | 端口范围 1-65535 |
| CorpID | 以 ww 开头 | 请输入正确的 CorpID |
| AgentID | 纯数字 | AgentID 必须为数字 |
| AppKey | 非空 | 请输入 AppKey |
| AppID | 以 cli_ 开头 | 请输入正确的 AppID |
| Webhook 地址 | 有效 URL | 请输入有效的 Webhook 地址 |
