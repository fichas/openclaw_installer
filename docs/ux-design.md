# OpenClaw 用户体验设计文档

## 1. 用户痛点分析

### 1.1 目标用户画像
| 用户类型 | 技术背景 | 主要诉求 | 潜在困难 |
|----------|----------|----------|----------|
| IT 管理员 | 中等 | 快速部署、稳定运行 | IM 平台配置复杂 |
| 开发者 | 较高 | 灵活配置、API 对接 | 多平台参数差异 |
| 业务负责人 | 较低 | 简单配置、快速见效 | 技术术语不理解 |

### 1.2 核心痛点识别

#### 痛点 1：IM 平台参数获取困难
- **问题**：企业微信、钉钉、飞书的配置参数分散在各平台后台，新手难以找到
- **影响**：配置过程中频繁切换查找文档，容易出错
- **解决方案**：提供详细的获取指引和图文教程链接

#### 痛点 2：配置错误难以排查
- **问题**：参数填写错误后，不知道具体哪里出错
- **影响**：反复尝试，挫败感强
- **解决方案**：实时验证 + 明确的错误提示 + 一键诊断

#### 痛点 3：多平台配置重复劳动
- **问题**：三个 IM 平台都要逐一配置
- **影响**：流程冗长，用户可能中途放弃
- **解决方案**：支持跳过、智能推荐、进度保存

#### 痛点 4：配置完成后不知如何验证
- **问题**：配置完成不知道是否成功
- **影响**：无法确认服务是否正常工作
- **解决方案**：配置完成页提供测试功能和状态检查

## 2. 文案规范

### 2.1 文案原则
- **简洁**：避免冗余，一句话说明白
- **友好**：使用"您"而非"用户"，避免指责性语言
- ** actionable**：告诉用户下一步该做什么
- **专业**：技术术语准确，必要时提供解释

### 2.2 通用文案

#### 按钮文案
| 场景 | 文案 | 说明 |
|------|------|------|
| 进入下一步 | 下一步 | 标准流程推进 |
| 返回上一步 | 上一步 | 返回修改 |
| 保存配置 | 保存并继续 | 强调保存动作 |
| 跳过当前 | 跳过此步 | 明确可跳过 |
| 完成配置 | 启动服务 | 最终动作 |
| 测试连接 | 测试连接 | 验证配置 |

#### 提示文案
| 场景 | 文案 | 说明 |
|------|------|------|
| 加载中 | 正在加载... | 通用加载 |

## 3. 错误场景处理

### 3.1 错误提示设计原则
1. **明确错误位置**：字段级错误直接在输入框下方显示
2. **说明错误原因**：告诉用户"为什么错了"
3. **提供解决方案**：告诉用户"怎么改"
4. **避免技术术语**：用用户能理解的语言

### 3.2 表单验证错误

| 字段 | 错误场景 | 错误提示 | 解决方案 |
|------|----------|----------|----------|
| AI 模型 | 未选择 | 请选择 AI 模型提供商 | 下拉选择一项 |
| API Key | 为空 | 请输入 API 密钥 | 从 AI 平台获取并填写 |
| API Key | 格式错误 | API 密钥格式不正确，应以 sk- 开头 | 检查密钥是否完整 |
| 端口 | 为空 | 请输入服务端口 | 填写 1-65535 之间的数字 |
| 端口 | 超出范围 | 端口范围应为 1-65535 | 修改端口数字 |
| 端口 | 被占用 | 端口 8080 已被占用 | 更换其他端口 |
| CorpID | 为空 | 请输入企业 ID | 从企业微信后台获取 |
| CorpID | 格式错误 | 企业 ID 应以 ww 开头 | 检查 CorpID 是否正确 |
| AgentID | 非数字 | 应用 ID 应为数字 | 只填写数字部分 |
| Secret | 为空 | 请输入应用密钥 | 从应用详情页获取 |
| AppKey | 为空 | 请输入应用标识 | 从钉钉开放平台获取 |
| AppSecret | 为空 | 请输入应用密钥 | 从应用详情页获取 |
| Webhook | 格式错误 | 请输入正确的 Webhook 地址 | 检查地址是否完整 |
| AppID | 为空 | 请输入应用 ID | 从飞书开发者后台获取 |
| AppID | 格式错误 | 应用 ID 应以 cli_ 开头 | 检查 AppID 是否正确 |

### 3.3 连接测试错误

#### 企业微信连接失败
```
错误标题：企业微信连接失败
错误详情：无法验证企业微信配置参数

可能原因：
• CorpID 填写错误
• AgentID 与 Secret 不匹配
• 应用未启用

建议操作：
1. 检查 CorpID 是否正确（以 ww 开头）
2. 确认 AgentID 和 Secret 来自同一应用
3. 在企业微信后台确认应用已启用

[查看详细教程] [重新测试]
```

#### 钉钉连接失败
```
错误标题：钉钉连接失败
错误详情：无法验证钉钉应用配置

可能原因：
• AppKey 或 AppSecret 错误
• 应用未发布
• 服务器 IP 不在白名单

建议操作：
1. 检查 AppKey 和 AppSecret 是否匹配
2. 在钉钉开放平台确认应用已发布
3. 将服务器 IP 添加到白名单

[查看详细教程] [重新测试]
```

#### 飞书连接失败
```
错误标题：飞书连接失败
错误详情：无法验证飞书应用配置

可能原因：
• AppID 或 AppSecret 错误
• 应用未发布
• 事件订阅配置不正确

建议操作：
1. 检查 AppID 和 AppSecret 是否正确
2. 在飞书开发者后台确认应用已发布
3. 检查事件订阅地址是否配置正确

[查看详细教程] [重新测试]
```

### 3.4 系统级错误

| 错误场景 | 错误提示 | 解决方案 |
|----------|----------|----------|
| 配置文件保存失败 | 配置保存失败，请检查磁盘空间 | 清理磁盘空间后重试 |

## 6. 无障碍设计

### 6.1 键盘导航
- Tab 键：在表单字段间切换
- Enter：提交表单或激活按钮
- Esc：关闭弹窗或取消操作
- 方向键：在选项间移动

### 6.2 屏幕阅读器支持
- 所有图标提供 aria-label
- 表单字段关联 label
- 错误提示使用 aria-live
- 进度变化使用 aria-valuenow

### 6.3 视觉辅助
- 错误字段边框变红 + 图标
- 必填字段标记红色星号 *
- 对比度符合 WCAG 2.1 AA 标准

```
"配置尚未完成，是否保存当前进度？"

```

```
"检测到您有未完成的配置，是否恢复？"

```

```

"网络连接失败，配置未能保存"
```
