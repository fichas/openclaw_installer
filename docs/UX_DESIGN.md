# OpenClaw 用户体验设计文档

## 1. 项目概述

### 1.1 目标用户
- **主要用户**: 中国企业 IT 管理员/技术人员
- **技术背景**: 具备基础 IT 知识，但可能对具体配置不熟悉
- **使用场景**: 从 U 盘运行安装器，配置企业 IM 集成

### 1.2 用户痛点分析
| 痛点 | 影响 | 解决方案 |
|------|------|----------|
| 网络环境受限 | 下载失败、超时 | 离线安装包、清晰的网络错误提示 |
| 权限不足 | 安装失败 | 前置权限检测、UAC 提示引导 |
| 端口占用 | 服务启动失败 | 自动检测、一键更换端口 |
| 配置复杂 | 填写错误 | 分步引导、字段说明、实时验证 |
| 缺乏反馈 | 不知道进度 | 详细进度条、状态说明 |

## 2. 文案规范

### 2.1 语气与风格
- **专业但不生硬**: 使用"请"、"建议"等礼貌用语
- **简洁明了**: 避免冗长，直击要点
- **积极正向**: 失败时给予解决方案，而非单纯报错
- **中文语境**: 使用中文标点，避免中英混排

### 2.2 常用术语表
| 英文术语 | 中文翻译 | 说明 |
|----------|----------|------|
| Webhook | Webhook / 回调地址 | 首次出现时标注英文 |
| Token | Token / 令牌 | 根据上下文选择 |
| Secret | 密钥 | 统一使用"密钥" |
| Port | 端口 | - |
| Service | 服务 | - |
| Configuration | 配置 | - |

### 2.3 按钮文案规范
- **确认类**: "开始安装"、"确认配置"、"保存并启动"
- **返回类**: "上一步"、"返回修改"
- **取消类**: "取消"、"跳过此步骤"
- **帮助类**: "查看帮助"、"联系技术支持"

### 4.2 企业微信配置页

**标题**: 配置企业微信
**引导文案**:
```
请先在 企业微信管理后台 → 应用管理 → 自建应用 中创建应用，
然后填写以下信息：
```

**表单字段**:

| 字段 | 标签 | 占位符 | 说明 |
|------|------|--------|------|
| corp_id | 企业 ID | wwxxxxxxxxxxxxxxxx | 我的企业 → 企业ID |
| agent_id | 应用 ID | 1000002 | 应用详情页获取 |
| secret | 应用密钥 | 点击右侧按钮查看 | 应用详情页获取 |
| webhook_url | Webhook 地址 | 系统自动生成 | 用于接收消息的回调地址 |

**字段说明展开**:
```
如何获取这些信息？

1. 企业 ID (CorpID)
   登录企业微信管理后台 → 我的企业 → 企业ID

2. 应用 ID (AgentId)
   应用管理 → 自建应用 → 点击应用名称 → 查看 AgentId

3. 应用密钥 (Secret)
   在应用详情页点击 "Secret" 右侧的 "查看" 按钮
   ⚠️ 请注意：Secret 只会显示一次，请妥善保存
```

**测试按钮**: [测试连接]（填写完整后可用）

## 5. 错误提示设计

### 5.1 错误提示通用规范
- **位置**: 表单字段下方或页面顶部（全局错误）
- **格式**: 图标 + 错误描述 + 解决方案
- **颜色**: 红色 (#F56C6C) 表示错误，黄色 (#E6A23C) 表示警告

### 5.2 具体错误场景

#### 权限不足
```
⚠️ 需要管理员权限

当前权限不足，无法完成安装。

解决方案：
1. 右键点击安装程序，选择"以管理员身份运行"
2. 或联系您的 IT 管理员获取权限

[查看详细步骤] [我已获取权限，重试]
```

#### 端口占用
```
⚠️ 端口 8080 已被占用

检测到端口 8080 已被其他程序使用（PID: 12345，进程: java.exe）

解决方案（推荐自动）：
[自动更换为 8081] [手动指定端口]

或手动解决：
1. 关闭占用该端口的程序
2. 在下方输入新端口号

新端口：[8081    ] [检测可用性]
```

#### 配置验证失败
```
✗ 企业微信配置验证失败

错误信息：CorpID 无效或网络连接失败

可能原因：
• 填写的 CorpID 不正确
• 企业微信服务器暂时无法访问
• 网络代理设置问题

建议操作：
1. 检查 CorpID 是否填写正确
2. 确认网络连接正常
3. 如需配置代理，点击 [网络设置]

[重新验证] [跳过，稍后配置]
```

#### 网络超时
```
⚠️ 连接超时

无法连接到服务器，可能是网络环境受限。

建议操作：
1. 检查网络连接是否正常
2. 确认是否需要配置代理服务器
3. 如处于内网环境，请联系网络管理员

[配置代理] [离线安装] [重试]
```

#### 磁盘空间不足
```
✗ 磁盘空间不足

安装需要至少 500MB 可用空间，
当前 C 盘仅剩 200MB。

解决方案：
1. [选择其他安装位置]
2. [清理磁盘空间]

或手动清理后重试。
```

## 10. 无障碍设计

### 10.1 键盘导航
- 所有交互元素支持 Tab 键导航
- 重要操作支持快捷键（如 Alt+S 保存）
- 模态框支持 ESC 键关闭

### 10.2 屏幕阅读器
- 所有图标配有 aria-label
- 错误提示自动朗读
- 进度变化实时播报

### 10.3 高对比度
- 支持系统高对比度模式
- 错误/成功状态不仅依赖颜色区分
